# Demo VM Readiness Milestone

This milestone prepares the current PoC for a clean demo environment, a VM move, and a polished
presentation layer.

## Milestone Name

**DVR-001: Demo, VM, And Product Console Readiness**

## Goal

Turn the working local PoC into a portable demo package that can be moved to a VM, run with a clean
Codex setup, produce evidence from that VM, and present as a polished product rather than a
developer-only Streamlit console.

This milestone should not expand agent scope. It should make the current successful flow easier to
move, prove, show, and explain.

## Outcomes

- Current repository is cleaned from irrelevant run/output files.
- Repository has a clear deploy/move checklist for a VM.
- Codex is installed on the VM through npm and authenticated with API-key login.
- The platform is moved to the VM and validated there.
- A clean demo run is executed on the VM.
- Current platform screenshots are captured and organized.
- Streamlit console replacement is planned as a real web app.
- Presentation, video outline, demo script, notes, and pitch are ready.

## Implementation Rule

Keep this milestone practical.

```text
Do not redesign the whole platform.
Do not add new agent roles.
Do not chase perfect production infrastructure.
Make the successful PoC portable, visible, and demo-ready.
```
