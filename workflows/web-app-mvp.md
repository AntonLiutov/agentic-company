# Web App MVP Workflow

This workflow handles small web application MVPs where the first delivery should be easy to run locally and simple to review.

## Default Stack

- Python
- Streamlit
- Environment variables from `.env`

## Phases

1. Intake normalization
2. Product scope
3. Technical plan
4. Implementation
5. QA review
6. Documentation and handoff

## Required Roles

- Intake Agent
- Team Assembler Agent
- Product Manager Agent
- Tech Lead Agent
- Fullstack Engineer Agent
- QA Agent
- Documentation / Handoff Agent

## Default Non-Goals

- Authentication
- Paid deployment setup
- Persistent database
- Docker Compose, unless explicitly requested
- Multi-provider model routing

## Exit Criteria

- The app can run locally
- Required environment variables are documented
- Missing configuration fails gracefully
- The README explains setup and usage
- A handoff summary lists known limitations and next steps
